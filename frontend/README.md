# frontend

## Project setup
```
pnpm install
```

### Compiles and hot-reloads for development
```
pnpm serve
```

### Type-checks, compiles and minifies for production
```
pnpm build
```

### Previews the production build locally
```
pnpm preview
```

### Lints files
```
pnpm lint
```
